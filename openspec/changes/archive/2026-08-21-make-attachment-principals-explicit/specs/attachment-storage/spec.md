## MODIFIED Requirements

### Requirement: 安全暂存动态附件

系统 MUST 将上传内容写入服务端隔离的临时目录，使用随机附件 ID，并在完整写入和校验后才使文件可读取。系统 MUST 仅为具有非空可信主体的访问上下文创建附件记录。

#### Scenario: 成功暂存

- **WHEN** 使用真实临时文件流和具有可信主体的上下文提交合法文件
- **THEN** 系统返回动态附件引用和正确大小
- **AND** 读取内容与提交内容一致

#### Scenario: 超过大小限制

- **WHEN** 文件流超过配置的大小上限
- **THEN** 暂存失败
- **AND** 不留下可读取的部分文件

#### Scenario: 路径越界输入

- **WHEN** 使用非服务端生成的附件 ID 读取文件
- **THEN** 系统拒绝请求
- **AND** 不访问附件根目录之外的路径

#### Scenario: 暂存上下文缺少主体

- **WHEN** 暂存调用未提供非空可信主体
- **THEN** 系统拒绝暂存
- **AND** 不创建附件目录或记录
