## Context

后端摘要列表、创建 API、当前会话本地状态和历史加载能力均可独立验证完成后，Chat 侧栏可以从静态状态升级为真实会话入口。

## Goals / Non-Goals

**Goals:** 拉取、展示、创建和选择主体范围内的会话。

**Non-Goals:** 不搜索正文、不重命名、删除、生成标题或一次加载完整消息。

## Decisions

- React Query 查询摘要列表，选择只更新当前 ID，由历史加载 Change 负责消息请求。
- 新建按钮先调用创建 API，刷新列表并选择新空会话。
- 初期以创建时间/无消息文案呈现摘要，持久化标题策略独立演化。

## Risks / Trade-offs

- [空会话较多] → 与创建 API 的可追溯语义一致；自动清理不在 UI Change 中处理。
