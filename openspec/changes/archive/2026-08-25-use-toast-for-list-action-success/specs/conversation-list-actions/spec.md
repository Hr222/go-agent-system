## MODIFIED Requirements

### Requirement: Chat 会话项提供菜单式管理入口

Chat MUST 为每个会话项提供更多操作入口，菜单 MUST 包含重命名、删除、置顶或取消置顶和分享占位项。重命名 MUST 复用话题概括更新能力，并在用户发起操作的会话项标题位置编辑；该会话处于编辑状态时 MUST 隐藏其更多操作入口，并将其原本预留的菜单空间提供给会话名称输入框，直到用户保存成功或取消编辑；分享占位项点击后不得发起请求或改变状态；菜单打开或关闭不得触发会话切换。

#### Scenario: 打开会话菜单

- **WHEN** 用户点击会话项的更多操作按钮
- **THEN** 页面展示该会话的操作菜单
- **AND** 点击菜单按钮不会选中或切换该会话

#### Scenario: 重命名会话

- **WHEN** 用户在菜单中选择重命名
- **THEN** 仅该会话项的标题替换为可编辑输入框以及确认、取消操作
- **AND** 会话项保留日期和置顶状态
- **AND** 该会话项不显示更多操作入口或已打开的操作菜单
- **AND** 输入框使用隐藏菜单后释放的可用宽度，确认和取消操作保持可点击
- **AND** 页面不在侧栏其他位置展示共享的重命名编辑器

#### Scenario: 保存会话名称

- **WHEN** 用户确认有效的新名称
- **THEN** Chat 调用主体范围话题概括更新接口
- **AND** 成功后该会话项恢复普通展示、显示保存后的名称和更多操作入口

#### Scenario: 取消重命名

- **WHEN** 用户取消正在编辑的会话名称
- **THEN** 页面丢弃未保存草稿并恢复该会话项原有标题
- **AND** 该会话项恢复更多操作入口
- **AND** 不发送更新请求

#### Scenario: 重命名保存失败

- **WHEN** 话题概括更新接口失败
- **THEN** 页面在目标会话项内保留用户正在编辑的内容并显示可重试状态
- **AND** 目标会话项继续隐藏更多操作入口
- **AND** 不覆盖服务端已有话题概括

#### Scenario: 置顶会话

- **WHEN** 用户在菜单中选择置顶或取消置顶
- **THEN** 页面调用主体范围置顶接口
- **AND** 列表刷新后反映新的置顶顺序
- **AND** 成功后页面通过 Ant Design 全局成功浮层显示“已置顶会话”或“已取消置顶”
- **AND** 侧栏不显示共享成功状态条

#### Scenario: 置顶达到上限

- **WHEN** 用户尝试置顶第 11 个会话且服务端返回置顶上限冲突
- **THEN** 页面保留原有会话列表和当前会话
- **AND** 页面显示可重试的受控失败提示，不显示成功反馈

#### Scenario: 分享占位项

- **WHEN** 用户在菜单中选择分享
- **THEN** 页面不发送网络请求
- **AND** 页面不写入剪贴板、不改变当前会话或列表状态

### Requirement: Chat 支持单项删除确认

Chat MUST 在单个会话删除请求前展示二次确认。删除当前会话后页面 MUST 清理当前会话状态；删除失败时 MUST 保留会话并显示失败提示。

#### Scenario: 取消删除

- **WHEN** 用户在删除确认中取消
- **THEN** 页面关闭确认状态
- **AND** 所选会话仍保留且不改变服务端数据

#### Scenario: 删除成功

- **WHEN** 用户确认删除且删除请求成功
- **THEN** 页面从列表移除目标会话
- **AND** 若当前会话被删除则清空消息和编辑状态
- **AND** 页面通过 Ant Design 全局成功浮层显示“会话已删除”
- **AND** 侧栏不显示共享成功状态条

#### Scenario: 删除失败

- **WHEN** 删除请求失败
- **THEN** 页面保留目标会话并显示失败提示
