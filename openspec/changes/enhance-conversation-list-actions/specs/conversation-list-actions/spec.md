## ADDED Requirements

### Requirement: 当前主体可以管理自己的会话

系统 MUST 提供当前可信主体范围内的置顶切换和删除操作。置顶操作 MUST 只改变目标会话的置顶状态；删除操作 MUST 只允许删除当前主体拥有的会话，并在成功后删除该会话关联的消息与事件事实。

#### Scenario: 置顶会话

- **WHEN** 当前主体为自己的会话发送置顶请求
- **THEN** 系统返回更新后的会话摘要且 `is_pinned` 为 `true`
- **AND** 后续列表将该会话置于未置顶会话之前

#### Scenario: 取消置顶会话

- **WHEN** 当前主体为已置顶会话发送取消置顶请求
- **THEN** 系统返回更新后的会话摘要且 `is_pinned` 为 `false`

#### Scenario: 删除会话及其事实

- **WHEN** 当前主体确认删除自己的会话
- **THEN** HTTP 返回 `204`
- **AND** 该会话、消息和事件不再能通过主体范围接口读取

#### Scenario: 管理其他主体的会话

- **WHEN** 当前主体尝试置顶或删除不属于自己的会话
- **THEN** 系统返回统一的会话不可用响应
- **AND** 不改变目标会话及其事实

### Requirement: 管理写操作拒绝无效输入

系统 MUST 拒绝无效 UUID、缺失可信主体或不符合请求结构的置顶请求，且在拒绝时不得改变持久化状态。

#### Scenario: 缺失可信主体

- **WHEN** 匿名调用方请求置顶或删除会话
- **THEN** 系统返回受控拒绝
- **AND** 不执行写操作

### Requirement: Chat 会话项提供菜单式管理入口

Chat MUST 为每个会话项提供更多操作入口，菜单 MUST 包含重命名、删除、置顶或取消置顶和分享占位项。重命名 MUST 复用话题概括更新能力；分享占位项点击后不得发起请求或改变状态；菜单打开或关闭不得触发会话切换。

#### Scenario: 打开会话菜单

- **WHEN** 用户点击会话项的更多操作按钮
- **THEN** 页面展示该会话的操作菜单
- **AND** 点击菜单按钮不会选中或切换该会话

#### Scenario: 重命名会话

- **WHEN** 用户在菜单中选择重命名并保存有效文本
- **THEN** 页面调用主体范围话题概括更新接口
- **AND** 会话项立即显示保存后的名称

#### Scenario: 置顶会话

- **WHEN** 用户在菜单中选择置顶或取消置顶
- **THEN** 页面调用主体范围置顶接口
- **AND** 列表刷新后反映新的置顶顺序

#### Scenario: 分享占位项

- **WHEN** 用户在菜单中选择分享
- **THEN** 页面不发送网络请求
- **AND** 页面不写入剪贴板、不改变当前会话或列表状态

### Requirement: Chat 支持单项删除确认

Chat MUST 在单个会话删除请求前展示二次确认。删除当前会话后页面 MUST 清理当前会话状态；删除失败时 MUST 保留会话并显示失败提示。

#### Scenario: 取消删除

- **WHEN** 用户在删除确认中取消
- **THEN** 页面关闭确认状态
- **AND** 所选会话仍保留且不改变服务端数据

#### Scenario: 删除成功

- **WHEN** 用户确认删除且删除请求成功
- **THEN** 页面从列表移除目标会话
- **AND** 若当前会话被删除则清空消息和编辑状态

#### Scenario: 删除失败

- **WHEN** 删除请求失败
- **THEN** 页面保留目标会话并显示失败提示
