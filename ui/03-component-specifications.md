# AetherFlow 组件设计规范

## 1. 导航系统组件

### 1.1 侧边栏导航 (Sider Navigation)

**尺寸规格**:
- 宽度: 252px
- 背景: 深色渐变 `linear-gradient(180deg, #111b31 0%, #0c1529 100%)`
- 右边框: `1px solid rgba(255,255,255,.07)`

**品牌区域**:
```
┌─────────────────────────────┐
│ 🌟  AetherFlow               │  <- 93px高度
│     AI 智能工作台            │
└─────────────────────────────┘
```

- Logo容器: 38x38px, 圆角11px
- Logo背景: `linear-gradient(135deg, #76a9ff, #b59bff)`
- Logo阴影: `0 10px 25px rgba(104,148,255,.27)`
- 品牌名称: 18px, 800字重, 颜色#d9e3ff
- 副标题: 10px, 字间距1.7px, 颜色#7d8aa6

**菜单项样式**:
```
┌─────────────────────────────┐
│ 🏠  控制台                  │  <- 42px高度
├─────────────────────────────┤
│ 💬  对话                    │
├─────────────────────────────┤
│ 🤖  智能体                  │
└─────────────────────────────┘
```

- 菜单项高度: 42px
- 水平边距: 16px
- 内边距: 13px
- 圆角: 9px
- 间距: 4px

**状态样式**:
```css
/* 默认状态 */
.menu-item {
  color: #9faac1;
  background: transparent;
}

/* 悬停状态 */
.menu-item:hover {
  color: #f3f6ff;
  background: rgba(255,255,255,.06);
}

/* 选中状态 */
.menu-item-selected {
  color: #061b42;
  background: #82aaff;
  font-weight: 750;
  box-shadow: 0 7px 18px rgba(80,134,255,.18);
}
```

## 8. 响应式适配

### 8.1 大屏 (>1280px)

- 标准布局
- 充分利用空间
- 完整功能展示

### 8.2 中屏 (1024px-1280px)

- 压缩边距: 38px → 28px
- 搜索框宽度: 270px → 230px
- 保持核心功能

### 8.3 小屏 (<1024px)

- 侧边栏可折叠
- 简化信息显示
- 触摸优化
