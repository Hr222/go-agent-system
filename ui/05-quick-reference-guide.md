## 设计检查清单

### 布局检查
- [ ] 侧边栏宽度是否为252px
- [ ] Header高度是否为72px  
- [ ] 间距是否遵循8px网格
- [ ] 圆角是否符合规范
- [ ] 响应式断点是否正确

### 色彩检查
- [ ] 是否使用设计变量
- [ ] 对比度是否达标 (4.5:1)
- [ ] 状态色是否语义正确
- [ ] 渐变方向是否一致

### 排版检查
- [ ] 字体家族是否统一
- [ ] 字号层级是否清晰
- [ ] 行高是否合适 (1.4-1.6)
- [ ] 字间距是否正确

### 交互检查
- [ ] 悬停状态是否明显
- [ ] 选中状态是否清晰
- [ ] 禁用状态是否可识别
- [ ] 加载状态是否友好

## 开发交接要点

### CSS变量映射
```css
:root {
  /* 品牌色 */
  --brand-primary: #4a6cf7;
  --brand-gradient-start: #76a9ff;
  --brand-gradient-end: #b59bff;
  
  /* 功能色 */
  --success: #2aa77c;
  --warning: #f59e0b;
  --error: #ef4444;
  
  /* 间距 */
  --space-xs: 4px;
  --space-sm: 8px;
  --space-md: 12px;
  --space-lg: 16px;
  --space-xl: 24px;
  
  /* 圆角 */
  --radius-sm: 8px;
  --radius-md: 9px;
  --radius-lg: 11px;
}
```

### 组件属性对应
```
Figma组件属性          React组件属性
─────────────────────────────────────
Label文本             label/children
Icon选择              icon={IconName}
State状态             state="default|hover|active"
Size尺寸              size="small|medium|large"
Variant变体           variant="primary|secondary"
```
