## 交互流程图

### 用户登录流程
```
启动应用
    ↓
登录认证
    ↓
显示主工作台
    ↓
┌───────────────┬───────────────┬───────────────┐
│   浏览控制台   │   开始对话     │  管理知识库    │
└───────────────┴───────────────┴───────────────┘
```

### 对话交互流程
```
选择/新建对话
    ↓
输入消息
    ↓
[显示用户消息]
    ↓
[LLM处理状态]
    ↓
[流式输出响应]
    ↓
[显示完整响应 + 元数据]
    ↓
提供反馈操作 (复制/点赞/重试)
```

### 知识库操作流程
```
进入知识库页面
    ↓
┌──────────────┬──────────────┐
│  查看概览     │  导入新文档   │
└──────────────┴──────────────┘
        ↓
    文档管理
        ↓
┌──────────────┬──────────────┐
│  文档搜索     │  知识检索     │
└──────────────┴──────────────┘
```
