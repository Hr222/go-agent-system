## 🔧 最后连接步骤 (仅需2分钟)

### 1. 安装Figma插件
1. 打开 **Figma Desktop** 应用
2. 点击右上角的 **插件图标** 或按 `Ctrl+Alt+P`
3. 选择 **"Development"** → **"Import plugin from manifest..."**
4. 导航到项目文件夹，选择：`figma-mcp-bridge/plugin/manifest.json`

### 2. 运行插件
1. 在Figma中按 `Ctrl+Alt+P` 再次打开插件列表
2. 找到 **"Figma MCP Bridge"** 插件
3. 点击运行

### 3. 验证连接
插件窗口应该显示：
```
✅ WebSocket Connected
🎉 Ready to create designs!
```
